# Carpeta Database - Parking Valet

Scripts SQL organizados:

01_schema.sql          -> Crea base de datos y esquemas
02_tables.sql          -> Crea todas las tablas
03_constraints.sql     -> Define constraints, índices, triggers
04_initial_data.sql    -> Inserta datos iniciales de prueba

Orden de ejecución recomendado:
01_schema.sql -> 02_tables.sql -> 03_constraints.sql -> 04_initial_data.sql
